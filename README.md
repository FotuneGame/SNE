# Решение нелинейных уравнений (СНУ)

Практическая работа — решение скалярного нелинейного уравнения и системы нелинейных уравнений численными методами.

## Запуск

```bash
npm install
npm start
```

Результаты сохраняются в папку `output/`.

## Часть 1 — Скалярное уравнение

```
-3·lg(x) + x² - 2 = 0,   x ∈ [1; 5]
```

Методы решения:

| Метод | Описание |
|-------|----------|
| **Бисекция** | Деление отрезка пополам, гарантированная сходимость |
| **Секущие** | Линейная интерполяция по двум точкам, без вычисления производной |
| **Монте-Карло** | Случайный перебор точек на отрезке |
| **Ньютон** | Метод касательных с аналитической производной, квадратичная сходимость |

## Часть 2 — Система нелинейных уравнений

```
cos(y) + x = 1.5
2y - sin(x - 0.5) = 1
```

Решается методом Ньютона с использованием матрицы Якоби и решением СЛАУ (метод Крамера) на каждой итерации.

- `output/results.json` — найденные корни, число итераций, невязки
